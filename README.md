## Project Overview
**Dear Diary** is a voice-first personal journaling platform that translates spontaneous, emotional spoken memories into tactile, curated scrapbook pages. It bridges the intimate nostalgia of physical stationery with modern privacy-first digital architecture.

### Core Value Pillars
- **Voice-to-Text Intimacy:** Speaks in native script (English, Malayalam, Hindi) using native device speech recognition without external AI servers.
- **Absolute Privacy (Local-First):** All journal entries, audio clips, and photos remain on the user's local device, secured by client-side AES-256 encryption.
- **Analog Scrapbook Tactility:** Lined, grid, dotted, and plain pages with white-bordered Polaroids, washi-tape clippings, and authentic handwriting typography.
- **"Tear a Page" Keepsake:** Safely export curated memory letters to friends via WhatsApp/Instagram with zero data leakage.
- **Mindful Manifestations:** Vision board and intentional reminders with Zomato-style discreet notifications.

## Technical Stack
- **Frontend:** HTML5, CSS3 (Design Tokens), Vanilla JavaScript (Zero bloated frameworks)
- **Speech Engine:** Native Browser `Web Speech API` (Multilingual: `en-IN`, `ml-IN`, `hi-IN`)
- **Storage:** Client-side `IndexedDB` & `LocalStorage` (Local-First data sovereignty)
- **Security:** Web Crypto API (AES-256 with PBKDF2 key derivation & Biometric WebAuthn)
- **Deployment:** GitHub Pages (100% Free, zero server subscription costs)
